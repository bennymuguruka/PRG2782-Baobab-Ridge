# Baobab Ridge Wildlife Rehabilitation Records System

A C# Windows Forms application for managing wildlife rehabilitation records.

## Technology
- C#
- Windows Forms
- .NET 8 or newer
- Git and GitHub

## Features
- Add animals
- View animal records
- Update animal records
- Delete animal records
- Generate summary reports

## Build and Run
Open BaobabRidge.sln in Visual Studio, restore dependencies,
build the solution, and run the application.

## Data Files
- animals.txt: Animal records stored as pipe-separated text.
- summary.txt: Generated animal summary report.

## Group Members
- Add member names and student numbers.
